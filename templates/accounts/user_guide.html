1Purpose of the System

The purpose of the Human Resource Information System (HRIS) is to provide an integrated and user-friendly platform for managing and automating core human resource processes within an organization.

The system centralizes employee information and streamlines HR activities such as employee management, recruitment and onboarding, attendance and leave management, payroll, benefits, performance appraisals, reporting, and analytics.

The system aims to:

  • Automate HR processes and reduce manual paperwork and administrative effort.
  • Centralize employee information in a single system for easy and secure access.
  • Improve attendance and leave management through systematic tracking and approval workflows.
  • Streamline payroll and benefits management, including statutory requirements such as EPF and ESI.
  • Support employee performance management through structured appraisal and feedback processes.
  • Provide reports and analytics to help HR and management make informed decisions.
  • Ensure secure and role-based access to protect employee and organizational information.
  • Improve operational efficiency, data accuracy, transparency, and employee experience across the organization.

2Application Flow

The HRIS application provides two types of user roles:

Employee HR / Admin

Users can access the system only after completing the registration and approval process.

2.1 Login and Registration Flow

  1. If a user is already registered and approved by HR/Admin, the user can directly log in to the system by entering their username and password.
  2. If a user is not registered, they must complete the registration process first.
  3. After registration, the account must be approved by HR/Admin.
  4. Once HR/Admin provides access and approves the account, the user can log in using their registered username and password.
  5. After successful login, the system displays the dashboard according to the user's assigned role.

2.2 Password Reset

  1. If a user forgets their password, they can initiate the password reset process by clicking on the "Forgot Password" link on the login page.
  2. The user is prompted to enter their registered email address or username.
  3. The system sends a password reset link to the user's registered email address.
  4. The user clicks on the password reset link and is redirected to a secure page where they can set a new password.
  5. After successfully setting a new password, the user can log in to the system using their updated credentials.

3Employee Application Flow

3.1 Employee Login

After an approved employee logs in using their username and password, the system redirects them to the Employee Dashboard, which provides an overview of the employee's account and recent activities.

Employee Dashboard displays:

UsernameAccount identifier
Employee IDUnique employee reference
DepartmentAssigned department
DesignationCurrent job title
Recent ActivitiesLatest account activity

The top navigation bar provides access to the main employee functions: Attendance Management, My Leave, Attendance Request, My Payroll, and View My Requests.

The profile icon on the right side of the navigation bar provides access to Profile and Logout.

3.2 Attendance Management

The Attendance Management section allows employees to view their attendance-related information, including:

  • Attendance logs
  • Overtime logs
  • Number of present days
  • Number of days in the selected month

This allows employees to monitor their attendance and working records.

3.3 My Leave

The My Leave section allows employees to manage and track their leave requests. The page displays remaining leave balance, a leave request form, and leave request history.

Submit Leave Request

  1. Open My Leave.
  2. Check the available/remaining leave balance.
  3. Enter the required leave details.
  4. Select the appropriate Leave Type.
  5. Submit the leave request — it is sent to HR/Admin for review.

Leave Request History

Employees can view their previous leave requests along with the decision/status provided by HR/Admin, tracking whether requests have been approved, rejected, or are still pending.

3.4 Attendance Request

The Attendance Request feature allows employees to submit an attendance request when their attendance could not be recorded through the normal mechanism, such as:

  • Biometric device not functioning
  • Employee working remotely
  • Employee working outside company premises
  • Attendance not recorded through the regular process

The employee submits the required details through the attendance request form; the request is then available to HR/Admin for review and decision.

3.5 My Payroll

The My Payroll section allows employees to view their payroll information, including:

  • Total Earnings
  • Total Deductions
  • Payroll Status
  • Generated Payslips

3.6 View My Requests

The View My Requests section provides employees with a history of their submitted requests. Employees can view attendance request history, check the status/decision of requests, and submit new requests — a centralized location to monitor requests and their outcomes.

3.7 Employee Profile

The profile icon is available on the right side of the navigation bar. Selecting it provides access to Profile and Logout.

By selecting Profile, the employee can view their personal and account information; where permitted, employees can also edit their available profile details.

Selecting Logout securely ends the employee's current session and returns them to the login page.

6HR Management

The HR Management menu contains Employees, Department Management, and Analytics.

6.1 Employee Management

The Employee Management page displays a list of employees registered in the system. HR/Admin can view employee details, edit employee details, delete an employee, or mark an employee as resigned.

Edit Employee

  1. Open HR Management → Employees.
  2. Locate the required employee.
  3. Click Edit.
  4. Update the required information.
  5. Save the changes.

Delete Employee

  1. Locate the employee.
  2. Click Delete.
  3. Review the confirmation message.
  4. Confirm the deletion.
Note: Deletion should be performed carefully because it permanently removes the employee record.

Mark Employee as Resigned

  1. Locate the required employee.
  2. Click Resigned.
  3. Confirm the action — the employee's status is updated accordingly.

6.2 Department Management

The Department Management section allows HR/Admin to add new departments, view existing departments, and remove departments.

6.3 Analytics

The Analytics section provides HR/Admin with analytical information about the organization, including:

  • Gender Ratio
  • Employees by Grade
  • Employees by Department
  • Recent Registrations
  • Recent Login Activities

This information helps HR/Admin monitor workforce information and activity.

7Attendance Management

The Attendance menu contains Biometric Logs, Attendance Logs, Leave Requests, Pending Requests, and Manage Holidays.

7.1 Biometric Logs

The Biometric Logs page provides an overview of biometric attendance information. HR/Admin can view total employees present today, employees on leave, and recent biometric logs.

7.2 Attendance Logs

The Attendance Logs page provides HR/Admin with employee attendance records, including the employee list, attendance details, and attendance records for employees.

7.3 Leave Requests

The Leave Requests section allows HR/Admin to review employee leave requests, view leave requests, approved leave, and leave request details.

7.4 Pending Requests

The Pending Requests section contains requests that require HR/Admin action. HR/Admin can review the request details and make the appropriate decision.

7.5 Manage Holidays

The Manage Holidays section allows HR/Admin to create/add holidays, view existing holidays, and manage the holiday list.

8Payroll Management

The Payroll menu contains Payroll Dashboard, Payslip, and Advance Requests.

8.1 Payroll Dashboard

The Payroll Dashboard provides an overview of payroll information, displaying:

  • Number of Payrolls Made This Month
  • Total Payroll / Net Salary Paid
  • Total Deductions
  • Overtime Costs

8.2 Payslip

The Payslip section contains employee payroll records. HR/Admin can view the list of employees and generate payslips for the respective employees.

Generate Payslip

  1. Open Payroll → Payslip.
  2. Locate the required employee.
  3. Click Generate — the system generates the employee's payslip.

Generated payroll records can be viewed from the payroll section.

8.3 Advance Requests

The Advance Requests section displays salary advance requests submitted by employees. HR/Admin can view salary advance requests, review request details, and make a decision on the request.

9My Menu – HR/Admin

The My Menu section provides HR/Admin users with access to their own employee-related information, including:

  • My Payroll
  • My Attendance
  • My Leave
  • My Attendance Request
  • View My Requests

These functions allow an HR/Admin user to access their own records in the same way as an employee, where applicable.
